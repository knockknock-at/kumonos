# 変更検出に内容ハッシュを使う

## 要点

更新日時だけに依存せず、内容ハッシュで入力の変更を判定する。同じ内容のコピーを再処理しない用途にも使える。

## 適用条件

- ネットワークドライブや同期フォルダを入力にする場合
- 見落とし防止を、処理速度より優先する場合

## 注意点

大量ファイルではハッシュ計算時間を測定する。更新日時とサイズによる一次判定を組み合わせる余地がある。

## 根拠

- 共有ファイル収集 / session-a-001 / 再実行テスト成功
- バックアップ点検 / session-b-014 / 同一内容の重複なし
- ほか2件
