# LLM送信前に資格情報をマスクする

## 要点

ログからAPI key、token、passwordらしい文字列を検出し、外部モデルへ送る前に置換する。

## 標準化候補になった理由

- 4つの独立した入力範囲で確認された
- 3件の検証済み根拠がある
- 未解決の矛盾がない

## 次の行動

セキュリティ担当者が誤検知と見落としを確認し、Operationの共通前処理へ反映するか判断する。

## 根拠

- 共有ファイル収集 / session-a-018 / マスクテスト成功
- 問い合わせ分析 / session-d-004 / token検出
- 運用記録整理 / session-e-011 / password検出
- ほか3件
