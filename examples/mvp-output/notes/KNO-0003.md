# 共有フォルダの更新を見落とす

## 要点

同期処理、時刻差、アプリケーションの保存方法により、更新日時だけでは内容変更を検出できない場合がある。

## 影響

新しい会話ログが知識化されず、判断画面の情報が古いままになる。

## 根拠

- 共有ファイル収集 / session-a-009 / 更新1件の見落とし
- 日次ログ収集 / session-c-031 / 同様の事象
- ほか1件
