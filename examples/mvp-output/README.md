# MVP出力サンプル

このフォルダは、KUMONOSが将来生成する出力の形を、実装前に確認するためのサンプルです。内容はすべて架空です。

## 確認方法

1. `index.html`をブラウザで開く
2. グラフのNodeまたは判断候補を選ぶ
3. 候補になった理由、根拠数、推奨する次の行動を確認する
4. `notes/`のMarkdownで詳しい内容と出典の形を確認する

## ファイル

| ファイル | 確認できること |
|---|---|
| `index.html` | 判断画面の完成イメージ |
| `graph.json` | NodeとEdgeの交換形式 |
| `graph.graphml` | 外部グラフツール向けの形式 |
| `decisions.json` | 判断候補の交換形式 |
| `notes/` | 人が読むMarkdownの形式 |
| `reports/latest-run.json` | 実行結果の形式 |

このHTMLはUIの設計サンプルであり、KUMONOSの処理結果を生成する実装ではありません。外部ライブラリやWebサーバーを使わず、ファイルを直接開けます。
